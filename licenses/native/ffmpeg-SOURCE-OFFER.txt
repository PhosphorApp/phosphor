FFmpeg — Corresponding Source Offer
===================================

Phosphor bundles the FFmpeg command-line tool (`dependencies/ffmpeg.exe`) and
invokes it as a separate process to remux downloaded audio/video streams
(stream copy, `-c copy`) and to extract single-frame thumbnails. FFmpeg is not
linked into Phosphor; it runs as an independent program.

Bundled build
-------------
  ffmpeg version 8.1-essentials_build-www.gyan.dev
  Configuration: --enable-gpl --enable-version3 (GPLv3)
  Source of binary: https://www.gyan.dev/ffmpeg/builds/

Because this build is configured with `--enable-gpl` and `--enable-version3`,
it is licensed under the GNU General Public License, version 3. The full license
text is in `ffmpeg-GPLv3.txt` in this folder.
