# Contributing to Phosphor

Thanks for your interest in improving Phosphor! Contributions of all kinds —
bug reports, fixes, new source plug-ins, and docs — are welcome.

## Before you start

- **Open an issue first** for anything non-trivial so we can agree on the
  approach before you write code.
- Keep changes focused; smaller pull requests are easier to review and merge.
- Match the style and patterns of the surrounding code.

## Contributor License Agreement

By opening a pull request, you agree to the terms of the
[Contributor License Agreement](CLA.md). In short: you keep ownership of your
work, but you grant the project's copyright holder a broad, irrevocable license
to use and relicense your contribution. The CLA must be accepted before a pull
request can be merged.

## Making a change

1. Fork the repo and create a branch off `master`.
2. Make your change and build the solution to confirm it compiles.
3. Open a pull request with a clear description of what and why.
